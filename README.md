# Documentary Video Hub | Rishi Production

**Documentary Video Hub** is a specialised landing page designed to host and showcase professional documentary content. Built for **Rishi Production**, the platform provides a high-impact, immersive viewing experience with integrated contact and production service highlights.

## 🌟 Key Features
- **Immersive Video Hero**: A dynamic, full-screen hero section with a pulsating play button and GLightbox integration for seamless video playback.
- **Responsive Navigation**: Smooth scrolling navigation for quick access to the video showcase and contact sections.
- **Service Showcase**: Highlighting the core expertise of Rishi Production in content writing, video editing, and web development.
- **Modern UI/UX**: Clean, dark-themed aesthetic with Google Fonts (Roboto & Raleway) and Bootstrap integration.

## 🛠️ Technical Stack
- **Frontend**: Semantic HTML5, CSS3, and Bootstrap 5.
- **Animation & Interactivity**: Vanilla JavaScript (ES6+), GLightbox for media modals.
- **Typography**: [Google Fonts](https://fonts.google.com/) integration.
- **Icons**: [Bootstrap Icons](https://icons.getbootstrap.com/).

## 📁 Repository Structure
- `index.html`: The primary landing page structure and video integration.
- `assets/css/`: Custom styles and Bootstrap overrides.
- `assets/js/`: Core logic for navigation and video modal management.
- `assets/vendor/`: External libraries (Bootstrap, GLightbox).

## 🚀 Deployment
This project is a static web application and can be hosted on GitHub Pages, Vercel, Netlify, or any standard web server.
